Product Requirements Document

Pastel Web Application for AI-Assisted Personalized Greeting & Occasion Cards

1. Executive Summary & Objectives

CardCraft AI is a modern, pastel-themed web application designed to empower users to easily craft, customize, and share high-quality digital and printable cards for various personal occasions. By integrating a 3-step structured creation wizard, real-time font and sticker customizers, and an embedded Grammarly-like AI writing assistant, users can produce heartfelt, grammatically polished, and aesthetically charming cards in minutes.

2. Target Audience & User Flow

Primary Audience: Individuals celebrating personal milestones, thanking mentors/friends, expressing apologies, or issuing event invitations who value thoughtful aesthetic design without needing complex design software expertise.

4-Step User Journey:

  1. Authentication: Google OAuth 2.0 Sign-In or Email Login.
  2. Category Selection (Step 1): Choice between Gratitude, Apology, Invitation, Birthday, Get Well Soon, and Special Occasion cards.
  3. Format & Theme Selection (Steps 2 & 3): Selection of card layout and pastel color themes.
  4. Interactive Studio & Editing: Custom text, typography, pastel color picking, sticker attachment, photo upload, AI text refinement, draft saving, and JPEG/PNG downloading.

3. Functional Requirements

FR-1: Auth & User Profile

Google OAuth 2.0 Sign-In with profile badge display in upper-right corner. User state persistence for drafts and collections.

FR-2: Card Creation Wizard

3-page guided wizard covering 6 card types, 4 layout formats, and 6 pastel visual themes.

FR-3: Grammarly-like AI Assistant

Integrated NLP assistant supporting 1-click grammar fixing, shortening, elongating, and tone transformations.

FR-4: Canvas Customization

Multi-font support, custom color picker, sticker placement, and photo attachment capability.

FR-5: Collections & Draft Storage

Dedicated "My Cards Collections" view to edit saved drafts, duplicate templates, or view history.

FR-6: UI Theme & Collapsible Navigation

Pastel green dominant color palette, left sidebar minimizable via arrow toggle, and dark/light theme switch.

4. Tech Stack & Non-Functional Requirements

Frontend Stack: HTML5, CSS3, JavaScript (ES6+), Google Web Fonts, html2canvas API.

Backend Stack: Node.js / Express, PostgreSQL / Supabase for card metadata & draft storage.

AI Integration: OpenAI GPT-4o-mini / Gemini API endpoints for real-time text rewriting and grammar polishing.

Performance: Sub-second UI state updates for live canvas edits and fast export rendering.
